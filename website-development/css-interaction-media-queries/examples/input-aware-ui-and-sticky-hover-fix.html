Naive Implementation

Flawed

Uses :hover without input media queries and hardcoded desktop button dimensions.

1. Sticky Hover Test:

On touch devices, tap this button. Notice how the blue hover state & scale transform remain stuck!

2. Hover Disclosure Test:

Try finding the "Quick View" button on a touchscreen device. It relies on :hover, so touch users cannot see or tap it easily.

Input-Aware Implementation

Resilient

Guards :hover with @media (hover: hover) and scales tap targets with @media (pointer: coarse).

1. Clean Tap / Hover Test:

On touch screens, tapping gives crisp active feedback without sticking. On mice, smooth hover scale is active! Touch targets auto-scale to 48px.

2. Adaptive Disclosure Test:

Automatically exposes as an inline button on touch devices, while preserving desktop hover reveal behavior!

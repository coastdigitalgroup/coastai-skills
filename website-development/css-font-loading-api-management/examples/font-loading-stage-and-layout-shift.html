High-Precision Typography Without CLS

When web fonts download asynchronously, unmanaged layout shifts degrade user experience. By using FontFace and document.fonts alongside metric overrides (ascent-override, size-adjust), text layout dimensions remain stable before and after the custom font is swapped in.

Canvas Text Rendering Safety

Canvas 2D contexts cannot dynamically update previously drawn bitmap text when fonts load. We await document.fonts.load() before executing fillText().

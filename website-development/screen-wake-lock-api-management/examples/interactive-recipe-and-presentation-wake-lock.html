Implementation Comparison

❌ Problematic Naive Implementation (Before)

The naive approach requests a lock once without tracking tab visibility or handling automatic release events. When the user switches tabs or locks the device, the lock is released permanently, leaving the app in a broken state when the user returns.

// NAIVE APPROACH: Lacks visibility lifecycle, accessibility, & error recovery
let lock = null;

document.getElementById('wakeBtn').addEventListener('click', async () => {
  // Bug 1: Throws uncaught error if page is hidden or not secure context
  lock = await navigator.wakeLock.request('screen');

  // Bug 2: No visibilitychange listener! Switch tabs once, and wake lock is lost forever.
  // Bug 3: No aria-pressed or aria-live updates for screen reader users.
  // Bug 4: No battery drain safeguard when unplugged.
});

✅ Robust Lifecycle Controller Implementation (After)

The robust approach handles automatic browser release on tab switch, re-acquires the lock on returning to the tab if user intent is still active, reports state to assistive technologies, and monitors battery thresholds.

// ROBUST APPROACH: Handled by ScreenWakeLockManager
class ScreenWakeLockManager {
  constructor() {
    this.sentinel = null;
    this.userWantsLock = false;
    this.initVisibilityListener();
  }

  async acquire() {
    if (!('wakeLock' in navigator) || document.visibilityState !== 'visible') return false;
    try {
      this.sentinel = await navigator.wakeLock.request('screen');
      this.userWantsLock = true;

      this.sentinel.addEventListener('release', () => {
        // Handle browser or system auto-release
        this.updateUI(false);
      });
      this.updateUI(true);
      return true;
    } catch (err) {
      console.error('Wake lock request rejected:', err);
      return false;
    }
  }

  initVisibilityListener() {
    document.addEventListener('visibilitychange', async () => {
      // Re-acquire automatically when returning to active tab
      if (document.visibilityState === 'visible' && this.userWantsLock) {
        await this.acquire();
      }
    });
  }
}

CSS Masking & Clipping Implementation

Solving edge fades, focus ring truncation, and punch-out badge compositing cleanly in CSS.

1. Scroll Container Edge Fading

Before Static Pseudo-Element Overlays

Uses ::before & ::after gradient divs. Blocks click events on edge chips and misaligns on window scroll or dynamic container sizes.

After Declarative CSS Mask Gradient

Uses mask-image: linear-gradient(...). Edge content cleanly fades without blocking pointer events or breaking touch scrolling.

2. Geometric Geometry & Keyboard Focus Protection

Before Clipped Interactive Container

clip-path directly on the focusable card cuts off native :focus-visible focus rings on bottom and right sides.

After Unclipped Focus Wrapper with Inner Shape

Focus ring is assigned to outer unclipped button wrapper. Inner .card-shape-inner applies clip-path without focus ring truncation.

3. True Transparent Avatar Punch-Out Cutouts

Before Border Color Emulation

Relies on hardcoded border: 3px solid var(--card-bg). Breaks whenever placed over dynamic hero gradients, dark/light themes, or image backgrounds.

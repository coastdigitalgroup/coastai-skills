# Before-and-After Example: Sample & Try-Before-You-Buy (TBYB) Optimization

## Case Study: Maison Luxe Parfums (Luxury D2C Fragrance & Skincare)

### Background & Baseline Problem

Maison Luxe Parfums sells high-end unisex eau de parfum ($165 for 50ml) and botanical night serums ($135 for 30ml). While paid social ads and influencer marketing drove high top-of-funnel traffic (220,000 monthly unique visitors), overall Product Detail Page (PDP) conversion rate hovered at **1.15%**.

Customer exit surveys and heatmaps revealed:
- **78% of PDP bounce visitors** cited sensory uncertainty ("I don't know how this scent smells on my skin" or "I'm hesitant to spend $165 without smelling it first").
- An informal physical sample program existed, but sample vials were only given away as free gifts at checkout for orders over $150 (benefiting existing buyers, not hesitant new visitors).
- CAC on Meta ads was escalating ($68 CAC), making top-of-funnel conversion unviable.
- Product return rates reached **18.4%** due to buyers disliking fragrance dry-down notes after unsealing full-size bottles.

---

### Before Intervention (Baseline Metrics)

- **PDP Visitor Conversion Rate (Full-Size Purchase)**: 1.15%
- **Monthly Full-Size Units Sold**: 2,530 units
- **Monthly Revenue**: $417,450
- **Return Rate on Full-Size Bottles**: 18.4% (465 returned bottles/month; $76,725 gross revenue refunded)
- **Blended CAC**: $68.00
- **Sampling Opt-In Rate**: 0.0% (No pre-purchase sample option available)
- **90-Day LTV**: $182.00

```text
[ Facebook / IG Ads ] ---> [ PDP: $165 Full-Size Eau de Parfum ]
                                   │
                                   ├──> 98.85% Bounce / Abandonment (Sensory Hesitation)
                                   └──> 1.15% Buy Full-Size ($165)
                                             │
                                             └──> 18.4% Return Rate ($76.7k Refunded/mo)
```

---

### The Intervention (Sample & TBYB Optimization)

Maison Luxe Parfums implemented a 3-part Sample & Try-Before-You-Buy Strategy:

#### 1. Discovery Set Architecture with 100% Full-Size Bounce Credit
- Created the **Maison Luxe Discovery Set**: 5 x 2ml spray vials featuring the top flagship scents for **$30**.
- Included a **100% Full-Size Digital Voucher ($30 credit)** valid for 30 days toward any 50ml or 100ml full-size bottle.
- Automated code delivery: The moment the carrier delivery scan occurs, an SMS and email deliver a 1-click magic link (`?discount=DISCOVERY30`) that pre-loads the $30 credit into their cart session.

#### 2. Dual-CTA PDP Buy-Box Design
Re-architected the main PDP buy box across all 50ml bottle product pages:

```text
┌─────────────────────────────────────────────────────────────────┐
│  Maison Luxe Eau de Parfum — 50ml                               │
│  $165.00                                                        │
│  ★★★★★ 4.9 (420 reviews)                                       │
│                                                                 │
│  [ ADD TO CART — $165 ]   <-- Primary Solid High-Contrast CTA  │
│                                                                 │
│  ─── UNSURE OF YOUR SCENT? TRY FIRST ──────────────────────────  │
│                                                                 │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │ 🧪 Order the Discovery Set ($30)                           │  │
│  │    Includes 5 x 2ml sprays + $30 credit toward full size. │  │
│  │    [ ADD DISCOVERY SET — $30 ]                            │  │
│  └───────────────────────────────────────────────────────────┘  │
│                                                                 │
│  ✓ Free Shipping & Returns  |  ✓ 100% Voucher Credit Guaranteed │
└─────────────────────────────────────────────────────────────────┘
```

#### 3. Post-Sample Conversion Lifecycle Flow
Built an automated 4-stage credit reminder flow:
- **Day 0 (Delivered)**: "Your Discovery Kit is here! Scan the QR code for testing tips."
- **Day 4**: "Found your signature scent? Apply your $30 voucher (1-click link inside)."
- **Day 14**: "Your $30 voucher expires in 16 days. See what other sample buyers chose."
- **Day 28**: "Final 48 Hours: Your $30 voucher expires soon."

### After Intervention (Measurable Results)

Within 90 days of deploying the optimized sampling program, Maison Luxe Parfums achieved dramatic lifts across all key growth metrics:

| Metric | Before Optimization | After Optimization | Delta / Impact |
| :--- | :--- | :--- | :--- |
| **PDP Full-Size Direct Conversion Rate** | 1.15% | 1.42% | +23.5% lift (improved confidence) |
| **Discovery Set Opt-In Rate** | 0.0% | **9.6%** of PDP visitors | +21,120 sample sets sold/mo |
| **Sample-to-Full-Size Conversion Rate** | N/A | **34.2%** within 30 days | 7,223 new full-size orders/mo |
| **Total Monthly Full-Size Units Sold** | 2,530 units | **10,347 units** | **+309% growth** |
| **Full-Size Return Rate** | 18.4% | **4.8%** | **73.9% reduction in returns** |
| **Blended CAC** | $68.00 | **$39.20** | **42.3% decrease in acquisition cost** |
| **Gross Monthly Revenue** | $417,450 | **$1,625,600** | **+289% revenue increase** |
| **Net Return on Sampling Investment (ROSI)** | N/A | **4.85x** | $4.85 net gross margin per $1 sample cost |

```text
[ Facebook / IG Ads ] ---> [ PDP Dual CTA ]
                               │
                               ├──> 1.42% Buy Full Size Direct ($165) [Return rate dropped from 18.4% to 4.8%]
                               └──> 9.60% Buy Discovery Set ($30)
                                         │
                                         └──> 34.2% Convert to Full-Size within 30 days ($135 net)
```

### Key Takeaways
1. **Sampling as a Profit Center**: Rather than losing money on free giveaways, selling the Discovery Set for $30 covered sample COGS ($4.20) and shipping ($3.80), making top-of-funnel customer acquisition self-funding.
2. **Returns Slashed by 74%**: Because customers tested scents on their own skin before purchasing $165 bottles, buyer remorse and return logistics fees plummeted.
3. **Automated Credit Redemption**: Injecting the $30 voucher directly via SMS/email URL parameters eliminated input friction and drove a 34.2% sample-to-full-size conversion rate.

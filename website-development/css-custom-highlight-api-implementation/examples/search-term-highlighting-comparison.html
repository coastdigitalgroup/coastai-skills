Modern: CSS Custom Highlight API

Zero Reflows

Try selecting text or editing inside this box while searching. Caret and selection are preserved perfectly!

The W3C CSS Custom Highlight API provides a mechanism for styling arbitrary text ranges by associating Range objects with a custom highlight name. By registering these ranges in the global CSS.highlights map, the rendering engine styles the text directly during the paint pipeline via ::highlight() pseudo-elements. This approach eliminates DOM node mutation, prevents layout thrashing, preserves contenteditable caret positions, and reduces memory overhead significantly compared to inserting DOM wrapper spans.

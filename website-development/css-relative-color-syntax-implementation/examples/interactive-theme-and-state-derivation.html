Dynamic token derivation, interactive state generation, and color space composition directly in native CSS.

Modern RCS Implementation Single Source of Truth

Hover, active, focus-ring, surface-tint, disabled, and complementary badges are dynamically derived from a single --brand-primary CSS variable in CSS.

Dynamic Surface Tint This card background and border are generated dynamically via oklch(from var(--brand-primary) 0.975 0.012 h). 
/* Pure CSS Derivation Rules */
.btn-primary {
  background-color: var(--brand-primary);
}
.btn-primary:hover {
  background-color: oklch(from var(--brand-primary) calc(l - 0.08) c h);
}
.btn-primary:focus-visible {
  box-shadow: 0 0 0 4px oklch(from var(--brand-primary) l c h / 0.45);
}
.badge-complementary {
  background: oklch(from var(--brand-primary) 0.92 0.08 calc(h + 180));
}
